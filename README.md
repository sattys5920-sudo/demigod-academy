# 데미갓 아카데미

그리스로마신화 12계보의 자손(데미갓)이 현대 학원에서 카드로 서열을 정하는 TCG 웹앱.
형광 팝 만화 톤 — 두꺼운 흰 아웃라인, 하프톤 도트, 라임·핑크 형광 대비.

## 화면

| 파일 | 화면 | 상태 |
| --- | --- | --- |
| `index.html` | 입장 — 가입 / 로그인 / 관리자 코드 | 완료 |
| `setup.html` | 프로필 만들기 — 아바타(문장 또는 사진) + 표시 이름 | 완료 |
| `app.html` | 본편 — 탭 4개 + 소환 연출 + 원정 대화 + 전투 + 결과 | 완료 |
| `firebase-init.js` | 화면들이 공유하는 파이어베이스 초기화 | — |
| `profile.js` | 12신 문장 · 프로필 저장 · 아바타 그리기 | — |

가입 직후 흐름: **가입 → 프로필 만들기 → 본편**. `app.html` 은 프로필이 없으면
`setup.html` 로 돌려보냅니다.

### 정보구조

탭은 **정확히 4개**입니다. 라벨은 기능형 2글자, 탭에 들어간 뒤 헤더 제목만
세계관 용어로 바뀝니다.

| 탭 | 헤더 제목 | 내용 |
| --- | --- | --- |
| 홈 | 신탁 | 오늘의 신탁 · 일일 임무 3줄 · 한 줄 남기기 · 피드(공지 / 다른 데미갓의 소환 · 원정 · 합성 기록) |
| 카드 | 계보 | 세그먼트 4분할 — 도감 / 덱 / 합성 / 강화 |
| 소환 | 소환 | 배너 · 1회 · 10회 뽑기 · 천장 · 등급 확률 · 이코르 보충 |
| 원정 | 원정 | 파티 편성 · 갈 수 있는 원정 목록 · 모의전 |

프로필·우편함·설정은 탭이 아니라 헤더 우측 아이콘 버튼입니다. 프로필 아이콘에는
내 아바타가 들어갑니다. 합성과 강화는 별도 탭이 아니라 카드 탭 안의 세그먼트입니다.

**소환 연출 · 원정 대화 · 전투 · 결과는 탭이 아닙니다.** 탭 위를 덮는 풀스크린
모드로, 들어가면 탭 바가 숨고 좌상단 나가기 버튼 하나만 남습니다.

```
소환 ──→ 소환 연출 ─┬─ 한 번 더
                    └─ 계보에서 확인 ─→ 카드 탭 · 도감

원정 ──→ 원정 대화 ─→ 전투 ─→ 결과 ─┬─ 돌아가기 ─→ 원정 탭
                                     └─ 계보에서 확인 ─→ 카드 탭 · 도감
```

### 원정 — TRPG 식 단체 대화

원정에 들어가면 진행자(**신탁**)가 상황을 던지고, 선택지를 고르면 d20 판정이
돌아갑니다. 성공·실패에 따라 이야기가 갈리고, 실패가 두 번 쌓이면 카드 전투로
넘어갑니다. 파티원에게 직접 말을 걸 수도 있습니다. 지금은 파티원 대사와 판정
결과가 화면 안에서만 돌아가고, 실시간 통신은 아직 붙지 않았습니다.

### 지금 실제로 움직이는 것

소환(천장·확률 포함), 이코르 증감, 강화 레벨·수치, 피드 글 올리기와 반응,
원정 대화와 주사위 판정, 탭·세그먼트·풀스크린 이동. 모두 새로고침하면
처음 값으로 돌아갑니다 — 저장은 아직 프로필만 됩니다.

빌드 단계가 없는 정적 HTML입니다. 다만 ES 모듈을 쓰기 때문에 `file://` 로 직접 열면
브라우저가 스크립트를 막습니다. 로컬에서 볼 때는 간단한 서버를 띄우세요.

```sh
python3 -m http.server 8000   # http://localhost:8000
```

`app.html` 과 `setup.html` 은 로그인 상태를 확인해서, 로그인하지 않았으면
`index.html` 로 돌려보냅니다. 확인이 끝날 때까지는 게이트 화면이 덮고 있어
내용이 잠깐 비치지 않습니다.

blur 없는 하드 섀도우(`10px 10px 0`), 작은 카드는 `rotate(-2deg ~ 2.2deg)`.

## 계정과 관리자 코드

로그인·가입은 **Firebase Authentication(이메일/비밀번호)** 를 씁니다. 이 게임은
이메일이 아니라 아이디로 입장하므로, 아이디를 이메일 형태로 바꿔 넘깁니다.
비밀번호는 구글 쪽에 해시로만 남고 이 저장소나 브라우저에 평문으로 저장되지 않습니다.

아이디에는 형식 제한이 없습니다 — 한글, 공백, 기호 모두 됩니다. 이메일 로컬 파트로
그대로 쓸 수 있는 아이디는 `<아이디>@demigod-academy.example` 로, 그 밖의 아이디는
UTF-8 바이트를 16진수로 바꿔 `u<hex>@demigod-academy.example` 로 담습니다.
대소문자는 구분하지 않고, 화면에 보여줄 원래 표기는 `displayName` 에 남습니다.

남아 있는 제한은 두 가지뿐이고 둘 다 바꿀 수 없는 것입니다.

- 아이디 길이: UTF-8 31바이트 (한글 10자 / 영문·숫자 31자). 이메일 로컬 파트가
  64자를 넘을 수 없어서입니다.
- 비밀번호 길이: 6자 이상. 파이어베이스 인증이 정한 최소 길이입니다.

`index.html` 의 `firebaseConfig` 값은 비밀이 아닙니다 — 파이어베이스 웹 앱 설정은
공개를 전제로 설계돼 있고, 실제 보호는 콘솔의 인증 설정과 보안 규칙이 합니다.

## 프로필

가입하면 바로 프로필을 만듭니다 — 12신 문장 중 하나를 고르거나 사진을 올려
아바타로 쓰고, 표시 이름을 정합니다. 사진은 정사각 160px 로 줄여 담습니다.

**프로필은 지금 브라우저(localStorage)에 기기별로 담깁니다.** 같은 아이디로 다른
기기에서 들어가면 프로필을 다시 고르게 됩니다. 표시 이름만 파이어베이스 계정의
`displayName` 에도 남겨 어디서든 따라옵니다. 기기 사이에서 이어지게 하려면
Firestore 를 붙여야 합니다.

## 관리자 코드

**관리자 코드는 아직 클라이언트 상수**라 소스를 열면 그대로 보입니다.
관리자 콘솔에 실제 데이터 편집 기능을 붙이기 전에 서버(Custom Claims 등)로
옮겨야 합니다.

## 배포

### GitHub Pages

저장소 **Settings → Pages** 에서 Source `Deploy from a branch`, Branch `main` / `/ (root)`.

게시 주소: `https://sattys5920-sudo.github.io/demigod-academy/`

### Firebase Hosting

```sh
npm install -g firebase-tools
firebase login
firebase deploy --only hosting
```

프로젝트는 `demig0d` 로 이미 지정돼 있습니다.
게시 주소: `https://demig0d.web.app`

파이어베이스 콘솔에서 미리 해둘 것:

1. **Authentication → Sign-in method → 이메일/비밀번호** 사용 설정
2. **Authentication → Settings → 승인된 도메인** 에 `sattys5920-sudo.github.io` 추가
   (Pages 쪽에서도 로그인이 되게 하려면 필요합니다)
