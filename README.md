# 데미갓 아카데미

그리스로마신화 12계보의 자손(데미갓)이 현대 학원에서 카드로 서열을 정하는 TCG 웹앱.
형광 팝 만화 톤 — 두꺼운 흰 아웃라인, 하프톤 도트, 라임·핑크 형광 대비.

## 화면

| 파일 | 화면 | 상태 |
| --- | --- | --- |
| `index.html` | 입장 — 가입 / 로그인 / 관리자 코드 | 완료 |
| `setup.html` | 프로필 만들기 — 아바타 + 표시 이름 | 완료 |
| `app.html` + `app.css` + `app.js` | 본편 — 탭 4개 + 풀스크린 7개 | **구조 완료 · 글 비어 있음** |
| `app-auth.js` | 입장 확인 · 프로필 읽기 | — |
| `firebase-init.js` · `profile.js` | 파이어베이스 초기화 · 12신 문장 | — |
| `data/*.json` | 시즌 · 카드 · 관계 · 시간표 · 퍼즐 · 경제 | `data/SCHEMA.md` 참고 |

설계는 `DESIGN.md`, 시즌 줄거리는 `season/season-01.md` 에 있다.

가입 직후 흐름: **가입 → 프로필 만들기 → 본편**. `app.html` 은 프로필이 없으면
`setup.html` 로 돌려보냅니다.

### 정보구조

탭은 **정확히 4개**입니다. 라벨은 기능형 2글자, 탭에 들어간 뒤 헤더 제목만
세계관 용어로 바뀝니다.

| 탭 | 헤더 제목 | 내용 |
| --- | --- | --- |
| 홈 | 신탁 | 접속 현황 · 현재 장과 사흘 단계 · 뽑기 배너 · 피드 · 연대기 입구 |
| 카드 | 계보 | 도감 / 덱 / 승급 / 봉납 / **관계도** |
| 일상 | 일상 | 시간표(수업·알바) / 사냥터 / 뽑기 / 상점 |
| 인연 | 인연 | 모모톡 — NPC가 말을 걸고, 답장하면 호감도가 오른다 |

프로필·우편함·설정은 탭이 아니라 헤더 우측 아이콘이다.

**풀스크린 일곱 개** — 연대기 · 조사 · 쪽지시험 · 모모톡 대화방 · 뽑기 연출 · 전투 · 결과.
들어가면 탭 바가 숨고 좌상단 나가기 버튼 하나만 남는다.

```
홈 ──→ 연대기
  └──→ 지금 할 일 ──→ 조사 / 시간표 / 사냥터
일상 ─→ 시간표 ──→ (끝나면) 쪽지시험 · 미니게임
  ├──→ 사냥터 ──→ 전투 ─→ 결과
  └──→ 뽑기 ───→ 뽑기 연출 ─→ 도감
인연 ─→ 모모톡 대화방 ─→ 답장 ─→ 호감도 · 관계선 공개
```

### 저장

저장은 **브라우저를 즉시 캐시로 쓰고 파이어스토어에 밀어 쓴다**(`store.js`).
SDK 를 못 불러오거나 Firestore 가 꺼져 있거나 네트워크가 막혀도 게임은 그대로
돌아가고, 켜지는 순간 같은 코드가 기기 사이를 이어 준다. 쓰기는 1.5초 모아서 한 번
보낸다.

보안 규칙은 `firestore.rules` 에 있다. 올리려면:

```sh
npm i -g firebase-tools && firebase login
firebase deploy --only firestore:rules
```

규칙의 뼈대는 셋이다.

- 세계(`world` · `seasons`)는 누구나 읽고 **아무도 못 쓴다.** 결산기만 Admin SDK 로 쓴다
- 내 것(`users/{uid}`)은 나만 쓴다. 다만 이름과 마지막 접속 시각은 서로 보인다
- 기여는 **사람당 장당 문서 하나**로 묶고 상한을 건다. 혼자 몰아서 분기를 뒤집지 못하게

### 지금 실제로 움직이는 것

뽑기(천장·확률 포함) · 이코르와 에테르 · 봉납 · 승급 · 시간표 걸기와 들르기 ·
쪽지시험 채점(문제 40개) · 사냥터 잠금과 전투 · 관계도 그리기 · 모모톡 답장과
호감도 · 연대기 · 피드. 저장은 브라우저(localStorage)라 기기별로 따로 남는다.

### 아직 비어 있는 것

**글이 전부 비어 있다.** 시즌 본문 스물넷 토막, 모모톡 대사, 카드 스탯과 경제 수치.
구조만 먼저 잡아 둔 상태이고, `data/SCHEMA.md` 에 무엇이 얼마나 찼는지 적어 두었다.

전투는 아직 **간단한 자동 교전**이다. 코스트·필드·스킬이 있는 진짜 TCG 규칙은 다음 단계다.

빌드 단계가 없는 정적 HTML입니다. 다만 ES 모듈을 쓰기 때문에 `file://` 로 직접 열면
브라우저가 스크립트를 막습니다. 로컬에서 볼 때는 간단한 서버를 띄우세요.

```sh
python3 -m http.server 8000   # http://localhost:8000
```

`app.html` 과 `setup.html` 은 로그인 상태를 확인해서, 로그인하지 않았으면
`index.html` 로 돌려보냅니다. 확인이 끝날 때까지는 게이트 화면이 덮고 있어
내용이 잠깐 비치지 않습니다.

## 디자인 시스템 v1

장식을 더해 고급스럽게 만들지 않습니다. 빼고 정확하게 맞춥니다.
한 화면에 시각적 중심은 하나, 강조색은 그 화면의 핵심 행동 하나에만.
구분은 테두리가 아니라 여백과 명도 차이로 줍니다.

### 색 (`theme.css` 의 `:root`)

| 역할 | 토큰 | 값 |
| --- | --- | --- |
| 화면 바탕 | `--bg` | `#0B1024` |
| 영역 구분 면 | `--surface` | `#121B38` |
| Secondary 버튼 · 진행 바 트랙 | `--elevated` | `#1A2648` |
| 본문 | `--text` | `#F4F6FF` |
| 보조 · 설명 | `--text-sub` | `#9CAAC9` |
| 비활성 | `--text-disabled` | `#6F7DA0` |
| Primary · 활성 탭 · 진행률 | `--accent` | `#55E6F2` |
| 눌림 | `--accent-pressed` | `#3CC3D0` |
| 알림 점 · 안 읽음 **전용** | `--alert` | `#FF648D` |
| 재화 아이콘 · 카드 등급(★) **전용** | `--reward` | `#FFC857` |
| 홈 전용 | `--hero-top` `--hero-mid` `--hero-slab` | `#1B2C66` `#141F4C` `#25398A` |

| 카드 등급 프레임 | `--grade-1` `--grade-2` `--grade-3` | `#6F7DA0` `#CBD6F2` `#FFC857` |

속성색(`--el-bolt` 등)은 **아이콘에만** 씁니다. 넓은 면에는 쓰지 않습니다.
카드가 카드로 보이는 것은 테를 두르는 일이 아니라 두 가지입니다 —
**등급마다 다른 프레임 색**(동·은·금)과 **그림을 안으로 물린 매트**.

### 글자

`Noto Sans KR` 한 벌. 숫자는 `font-variant-numeric: tabular-nums`.

| 쓰임 | 크기 / 굵기 |
| --- | --- |
| Display — 챕터 제목 | 34 / 900 / 자간 −0.03em |
| Title — 화면 제목 | 22 / 800 |
| Heading — 섹션 제목 | 17 / 800 |
| Body | 15 / 500 |
| Caption | 13 / 500 · `--text-sub` |
| Label — 영문 라벨 | 12 / 700 / 자간 0.1em · `--accent` |
| Number | 15 / 700 |

최소 글자 크기는 11px(하단 탭 라벨), 그 밖의 정보는 12px 이상.
`word-break: keep-all` 을 전역으로 걸어 낱말 중간에서 끊기지 않게 합니다.

### 간격과 모양

간격 4 / 8 / 12 / 16 / 24 / 32 (`--s1`~`--s8`), 화면 좌우 여백 16, 그룹 사이 24~32.
라운드는 버튼 12 · 면 16 · 카드 8 · 칩 18.

**사선은 두 곳에만** 씁니다 — 홈 챕터 면의 아래 모서리, Primary 버튼의 오른쪽 끝.
네온 발광, 다중 그라데이션, 모든 요소에 두르는 테두리·그림자는 쓰지 않습니다.
`npm run lint` 의 `lint:refs` 가 이 금지 사항을 전수 검사합니다.

### 버튼은 세 종류

| 종류 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| Primary `.btn.primary` | 높이 56 · `--accent` · 오른쪽 끝 사선 | **화면당 하나**, 그 화면의 핵심 행동 |
| Secondary `.btn` | 높이 48 · `--elevated` · 테두리 없음 | 나머지 행동 |
| Tertiary `.iconbtn` / `.linkbtn` | 44×44 터치 영역 · 아이콘 24 | 머리 줄 아이콘, 텍스트 링크 |

아이콘은 24px · `stroke 1.8` · 라운드 조인 라인 아이콘 한 세트. 이모지는 쓰지 않습니다.

## 계정과 관리자 코드

로그인·가입은 **Firebase Authentication(이메일/비밀번호)** 를 씁니다. 이 게임은
이메일이 아니라 아이디로 입장하므로, 아이디를 이메일 형태로 바꿔 넘깁니다.
비밀번호는 구글 쪽에 해시로만 남고 이 저장소나 브라우저에 평문으로 저장되지 않습니다.

아이디에는 형식 제한이 없습니다 — 한글, 공백, 기호 모두 됩니다. 이메일 로컬 파트로
그대로 쓸 수 있는 아이디는 `<아이디>@demigod-academy.example` 로, 그 밖의 아이디는
UTF-8 바이트를 16진수로 바꿔 `u<hex>@demigod-academy.example` 로 담습니다.
대소문자는 구분하지 않고, 화면에 보여줄 원래 표기는 `displayName` 에 남습니다.

남아 있는 제한은 두 가지뿐이고 둘 다 바꿀 수 없는 것입니다.

- 아이디 길이: UTF-8 31바이트 (한글 10자 / 영문·숫자 31자). 이메일 로컬 파트가
  64자를 넘을 수 없어서입니다.
- 비밀번호 길이: 6자 이상. 파이어베이스 인증이 정한 최소 길이입니다.

`index.html` 의 `firebaseConfig` 값은 비밀이 아닙니다 — 파이어베이스 웹 앱 설정은
공개를 전제로 설계돼 있고, 실제 보호는 콘솔의 인증 설정과 보안 규칙이 합니다.

## 프로필

가입하면 바로 프로필을 만듭니다 — 12신 문장 중 하나를 고르거나 사진을 올려
아바타로 쓰고, 표시 이름을 정합니다. 사진은 정사각 160px 로 줄여 담습니다.

**프로필은 지금 브라우저(localStorage)에 기기별로 담깁니다.** 같은 아이디로 다른
기기에서 들어가면 프로필을 다시 고르게 됩니다. 표시 이름만 파이어베이스 계정의
`displayName` 에도 남겨 어디서든 따라옵니다. 기기 사이에서 이어지게 하려면
Firestore 를 붙여야 합니다.

## 관리자 코드

**관리자 코드는 아직 클라이언트 상수**라 소스를 열면 그대로 보입니다.
관리자 콘솔에 실제 데이터 편집 기능을 붙이기 전에 서버(Custom Claims 등)로
옮겨야 합니다.

## 배포

**push 하면 자동으로 올라간다.** `.github/workflows/firebase.yml` 이 저장소 시크릿
`FIREBASE_SERVICE_ACCOUNT` 로 보안 규칙과 호스팅을 함께 배포한다.

| 주소 | 무엇 |
| --- | --- |
| https://demig0d.web.app | Firebase Hosting (자동 배포) |
| https://sattys5920-sudo.github.io/demigod-academy/ | GitHub Pages |

서비스 계정에는 **Firebase Admin** 역할이 필요하다. Admin SDK 기본 역할만으로는
`firebaserules.googleapis.com` 에 403 이 난다.

수동으로 올릴 때:

```sh
npm i -g firebase-tools && firebase login
firebase deploy --only firestore:rules,hosting
```

파이어베이스 콘솔에서 미리 해둘 것:

1. **Authentication → Sign-in method → 이메일/비밀번호** 사용 설정
2. **Authentication → Settings → 승인된 도메인** 에 `sattys5920-sudo.github.io` 추가
   (Pages 쪽에서도 로그인이 되게 하려면 필요하다. `demig0d.web.app` 은 기본으로 들어 있다)
3. **Firestore Database** 생성 (프로덕션 모드)
